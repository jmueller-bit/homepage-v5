# So kommt etwas auf unsere Website

Für alle Lehrer:innen im Astrid Lindgren Zentrum · eine Seite zum Ausdrucken

Alles wird in **Contentful** gepflegt: <https://app.contentful.com> → Space **alz-home**.
Was Sie dort **veröffentlichen**, steht nach wenigen Sekunden auf der Website. Ein gespeicherter Entwurf bleibt unsichtbar.

---

## Einen Beitrag für „Aktuelles“ schreiben

1. Oben auf **Content** klicken, dann auf den blauen Knopf **Eintrag hinzufügen** → **Neuigkeit**.
2. **Titel** eintragen, z. B. „Herbstwanderung an der Liesing“.
3. **Inhalt**: den Text schreiben. Für ein Foto im Text: in der Leiste über dem Textfeld rechts **+ Einbetten** → **Medien** → Foto hochladen.
4. Alles andere darf leer bleiben. Die Website nimmt dann automatisch das Datum von heute, die ersten zwei Sätze als Vorschau und das erste Foto als Titelbild.
5. Rechts auf den grünen Knopf **Veröffentlichen**. Fertig.

## Fotos für die Galerie

1. **Content** → **Eintrag hinzufügen** → **Fotoalbum**.
2. **Titel**: Name des Albums, z. B. „Herbstwanderung Oktober 2026“.
3. **Fotos**: auf **Add media** → **Hochladen** und mehrere Fotos auf einmal hineinziehen.
4. Bei jedem Foto in das Feld **Description** kurz schreiben, was zu sehen ist (z. B. „Kinder bauen ein Insektenhotel“). Das lesen blinde Menschen vor.
5. **Veröffentlichen**.

> Fotos mit erkennbaren Kindern nur hochladen, wenn die Eltern zugestimmt haben.

## Einen Termin für die Startseite eintragen

1. **Content** → **Eintrag hinzufügen** → **Termin**.
2. **Titel** (z. B. „Kleiner Tag der offenen Tür“), **Datum**, bei Bedarf **Uhrzeit** (z. B. „14:30–17:00“) und **Ort** (leer = im Zentrum, oder z. B. „Online“).
3. **Veröffentlichen**. Die Startseite zeigt automatisch immer den nächsten Termin.

---

## Etwas ändern oder wieder entfernen

- **Ändern:** Eintrag in der Liste unter **Content** anklicken, ändern, wieder **Veröffentlichen** klicken.
- **Von der Website nehmen:** rechts **Status ändern** → **Veröffentlichung aufheben**. Der Eintrag bleibt als Entwurf erhalten.
